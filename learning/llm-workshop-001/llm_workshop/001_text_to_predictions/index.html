Explore the new browser visual lab

Open the model follows actual computations with interactive matrices, attention connections and generation. See the 90-minute workshop route. The Python lab and the detailed written walkthrough remain available below.

New: the complete step-by-step walkthrough

Follow one prompt from text to a next-token prediction, with every matrix shape, color scale and attention operation explained. Includes interactive numerical examples for embedding addition and masked softmax, plus a translation of the desktop messages.

Launch the Python visual lab

conda activate llm-workshop
python llm_workshop/001_text_to_predictions/ui.py

Use the left menu to visit all nine topics. Component views update as you edit text; training and generation have explicit controls. The terminal demos remain separate.

First inspect a tokenizer with no neural network. Then follow a prediction through an untrained model.

1. Show the tokenizer algorithm

conda activate llm-workshop
python llm_workshop/001_text_to_predictions/tokenizer_demo.py --step

Open tokenizer_demo.py in the editor. Press Enter at each stage: text → character tokens → vocabulary → IDs → recovered text. Change TEXT or pass --text "the dog ran.".

IDs come from the printed lookup table. No model training, HTML or plotting is involved.

2. Optional: how a tokenizer learns subwords

python llm_workshop/001_text_to_predictions/bpe_demo.py --step --word lower

Open bpe_demo.py. Count adjacent pairs, see each merge, then apply the frozen rules to an input. Try changing training-word frequencies. This simplified character BPE is not a production byte-level tokenizer. The default input lowest also demonstrates unknown-character handling.

3. Trace the neural network

python llm_workshop/001_text_to_predictions/lesson.py --step

Open lesson.py: tokenize → shift targets → initialize → embedding lookup → blocks → vocabulary scores → probabilities → loss → sample. It prints real values and contains no presentation code. Edit DEMO_TEXT, RANDOM_SEED or SAMPLE_TEMPERATURE one at a time.

The implementation of attention and blocks remains in tiny.py, shared with the trainer. The explicit demonstration path checks that its scores and loss match that implementation.
