What did this model train on?

Start with biology. Adapt the same base to finance. Compare a finance-only run with one that also revisits biology. These curves and samples were measured in Python; changing a selection here runs no training.

What do these curves measure?

Biology / finance validation: average next-token error over every non-padding target in the held-out 500 / 200 records. These records never receive gradient updates. Lower is better. A rising biology curve during finance training is evidence of forgetting on this probe.

Training batch: error on the most recent batch before its update, not the whole training corpus. Replay batches mix the two domains. Do not compare character and word loss values directly: their prediction units differ.

The runs use fixed epoch budgets and retain the final checkpoint. No early stopping or best-checkpoint selection. Exact texts are separate, but templates and vocabulary overlap; this is not a test of broad factual knowledge.

Vocabulary, replay fairness and scope

Each model fixes its vocabulary before training, using the union of biology-training and finance-training text. This reserves finance IDs in advance; it does not update model weights on finance during biology pretraining. Validation text never fits the vocabulary. In these recordings, validation contains no unknown tokens.

The CSV word route uses whole words, separate digits and punctuation—not BPE. The original 52-entry word classroom model remains a separate experiment. The character CSV model also has its own larger alphabet and context.

Both adaptation runs start from identical biology weights, visit the same finance records in the same order, and use the same number of updates. Replay adds 8 biology records to each full batch of 32 finance records (20% of records; not necessarily 20% of target tokens). It therefore uses extra data and compute. All weights are trainable here; this is full fine-tuning, separate from the tiny LoRA adapters in character chapter 06.

How does this compare with large-model training?

Published pretraining examples: Llama 3.1 405B (2024): over 15 trillion tokens; DeepSeek-V3 (2024): 14.8 trillion; Qwen3 (2025): about 36 trillion.

These are dated public examples, not a ranking of today's best models or a minimum data requirement. Training-token budgets are not counts of unique words or sentences. Data quality, diversity, model size and compute all matter. A small domain adaptation set and training a general model from scratch serve different purposes.
