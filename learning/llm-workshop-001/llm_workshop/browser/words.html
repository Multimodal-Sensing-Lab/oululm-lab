Give each word an ID, follow its numbers, then watch the model choose a continuation. This is the same TinyGPT transformer used in the character workshop, trained separately on a small, controlled corpus.

What is live? Predictions and matrices are computed here from real saved weights. Training happened in Python; switching “before” and “after” loads a checkpoint. The corpus uses familiar sentence templates. Fluent examples here are evidence of those patterns, not broad English or subject expertise.

Run your own word experiment

Both word checkpoints and their measured training results are bundled. You can explore this page offline immediately. For a new experiment, train in Python, inspect the saved report, then export it to the browser. The Python and browser sessions are separate.

python -m llm_workshop.words.train --device auto --steps 600 --output-dir runs/words_my_run --live-plot
python -m llm_workshop.words.demo --checkpoint runs/words_my_run/after.pt --inspect --step
python -m llm_workshop.words.export --run-dir runs/words_my_run

Python writes an updated progress.png during training and an SVG on completion. Use --live-plot for a desktop window. Browse all input datasets and CSV training recordings.
