# Python package · OuluLLM Lab

Start with the [workshop README](../README.md) and [participant guide](../STUDENT_GUIDE.md). The main entry point is the [interactive browser](../index.html), with a [word companion](browser/words.html), [glossary](glossary.html), [detailed reading](001_text_to_predictions/walkthrough.html) and [Python lab](python-lab.html).

Numbered folders contain the runnable examples and topic-specific student guides. `tiny.py` contains the shared Transformer implementation. `words/` contains the controlled word experiments; `domains/` contains data preparation, training and the local generation server.

Run terminal commands from this package's parent directory, `learning/llm-workshop-001`.
