Start here

Install the core Python requirements and run commands from learning/llm-workshop-001. The browser and Python use separate model sessions. Every example has short comments and can pause between concepts with --step.

python llm_workshop/001_text_to_predictions/tokenizer_demo.py --step
python llm_workshop/001_text_to_predictions/bpe_demo.py --word lower --step
python llm_workshop/003_attention_and_transformer/demo.py --step

Word and domain experiments

Word training and generation · 500-update domain experiments · Biology → finance and replay.

python -m llm_workshop.words.demo --checkpoint runs/words_classroom_01/after.pt --text 'the small cat' --inspect --step
python -m llm_workshop.domains.serve

Training can use CPU or CUDA. The local domain server uses CPU inference. All supplied checkpoints are tiny workshop-trained models, not downloaded general assistants.
