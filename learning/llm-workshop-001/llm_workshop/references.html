What the demos actually calculate

TinyGPT is the numerical model. The JavaScript engine computes embeddings, both transformer blocks, vocabulary scores and sampling from exported weights. JavaScript and PyTorch differ in floating-point arithmetic; tests compare their results with explicit tolerances.

Training curves and checkpoints are genuine recorded Python runs. Browser training views inspect them without changing weights. The evidence activity retrieves text and assembles a prompt; it does not generate a fictional answer. The optional domain server generates new text from local saved weights.
