# Learning toolkits

Start with [Workshop 001 — LLM basics: Open the model](llm-workshop-001/README.md): characters and words, tokenization, embeddings, attention, training, adaptation, retrieval and evaluation.

Each workshop is self-contained. Run its commands from its own directory. The first workshop includes small data and weights so participants can reproduce the examples without downloading a large model.

Future VLM and multimodal workshops will receive separate directories. Original learning material and code are MIT licensed; data exceptions are documented at the repository root.

The browser entry point is [llm-workshop-001/index.html](llm-workshop-001/index.html). Future toolkits can live beside it, for example `vlm-workshop-001/`, each with its own README and index.html.
